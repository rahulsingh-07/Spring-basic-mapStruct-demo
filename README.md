# Basic MapStruct 

A simple Spring Boot project demonstrating how to use **MapStruct** to map between DTOs and Entities in a clean and efficient way.

## 🚀 Features
- Convert between `StudentModel` (Entity) and `StudentDIO` (DTO) using MapStruct.
- Basic CRUD operations using Spring Data JPA.
- REST APIs for saving and retrieving student data.
- Integration with MySQL database.
